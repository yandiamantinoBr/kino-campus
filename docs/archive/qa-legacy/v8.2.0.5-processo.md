# Processo de QA — V8.2.0.5

## Verificações rápidas com `git grep`

Use os comandos abaixo com sintaxe válida:

```bash
git grep -n 'href="' -- '*.html'
git grep -n 'href="' -- '**/*.html'
git grep -n 'caronas.html' -- .
git grep -n 'compra-venda.html' -- .
```

> Nota: `--` separa as opções do `pathspec`, evitando erro de parsing.
