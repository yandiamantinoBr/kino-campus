# Triage V8.2.3

## 1. Create post quebra (P0)
- **Problema**: Erro `Cannot assign to read only property "createPost"...`
- **Como reproduzir**:
  1. Acessar fluxo de criação de post.
  2. Tentar disparar submit de salvamento (ex: chamar API global pra injeção).
  3. Consultar Developer Tools acusando objeto read-only/frozen.
- **Onde investigar**: `assets/js/controllers/create-post.controller.js` (ou `kc-api.client.js`).

## 2. Dados fantasmas hardcoded (P1)
- **Problema**: Nomes estáticos e ranks fake como 'Maria Souza' ou 'Rafael Almeida' preenchendo a tela via HTML fixo.
- **Como reproduzir**:
  1. Acessar telas como `index.html` ou `compra-venda-feed.html`.
  2. Olhar cartões gerados fora de ciclo JS-dinâmico (antes da injeção do SDK de Backend ou Supabase mode).
- **Onde investigar**: `index.html`, `compra-venda-feed.html`, templates HTML soltos.

## 3. Comentários inconsistentes (P1)
- **Problema**: Feedback divergente da quantidade de comentários contidos no Supabase versus a interface pré-view do card de timeline.
- **Como reproduzir**:
  1. Localizar um post com N comentários reais.
  2. Em scroll do feed ele exibirá 0, abrindo a página restrita ele mostrará o número real (N).
- **Onde investigar**: `.select(...)` em `kc-supabase.client.js` ou parser `normalizeBasePost` na modelagem do item.

## 4. Likes/Upvotes buggados (P1)
- **Problema**: Cliques sequenciais de upvote/downvote fazem o contador da UI se perder, não possuindo trava nem matemática robusta de reversão.
- **Como reproduzir**:
  1. Efetuar Múltiplos toques rapidamente (spam) sobre o botão hot ou cold de votação de uma postagem do feed.
- **Onde investigar**: Interação/Binding em listener da classe `.hot` / `.cold`, presente no utilitário de botões `kc-core.js`.

## 5. Data crua ISO (P1)
- **Problema**: O sistema de posts não humaniza as datas nativas de banco (Timestamp com TimeZone).
- **Como reproduzir**:
  1. Exibir cartão via timeline. As postagens datam '2026-02-23TXX:XX...Z'.
- **Onde investigar**: Utilitário em view model middleware responsável por traduzir timestamps.

## 6. Busca com layout quebrado (P1)
- **Problema**: Cartões espremidos no canto esquerdo ou comportamentos disfuncionais simulando coluna vazia no grid do app.
- **Como reproduzir**:
  1. Preencher termo na barra superior móvel ou search global e pressionar buscar.
  2. Ver `search-results.html`.
- **Onde investigar**: Container principal `main` para tags de estilo cascateante injetadas em desktop / viewports maiores em páginas non-sidebar.

## 7. Mobile: detalhe do post sem padding (P2)
- **Problema**: Excesso de colagem da imagem ou descritivos na parede móvel e sobreposição de top header no celular.
- **Como reproduzir**:
  1. Alterar largura de tela para `max-width: 576px`.
  2. Visualização dos ícones do app top e body layout lateral.
- **Onde investigar**: Media queries ou hardcoded inlines localizadas nos headers do CSS principal.

## 8. Mobile: bottom nav com ruído / Scroll Carrossel (P2)
- **Problema**: Fricção ao tentar descer a aba vertical e nav bars com overflow.
- **Como reproduzir**:
  1. Simular touchscreen, swipar verticalmente por cima de componentes slider carrossel (top contributors). Atua de forma falha (scroll-Y trava).
- **Onde investigar**: Rules CSS flexíveis ou de `touch-action` associados a `.kc-ranking-users` e/ou o bottom container.

## 9. Infinite scroll (P2/P3)
- **Problema**: Substituição de trigger braçal por rolagem imperceptível.
- **Como reproduzir**:
  1. Dar scrolldown no limitador inicial num feed repleto de mock/local records.
  2. Precisará da intervenção clicar "Carregar Mais".
- **Onde investigar**: `.kc-feed-pager` controller script (IntersectionObserver tracking wrapper).
