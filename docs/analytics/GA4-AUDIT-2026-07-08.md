### Fase 2 (próxima sessão) — Server-side via GA4 Data API

**Requer credenciais Yan (NÃO colar no chat):**

1. Yan cria Service Account GCP:
   ```
   https://console.cloud.google.com/iam-admin/serviceaccounts
   → Create service account
   → Name: "kino-ga4-reporter"
   → Role: "Firebase Analytics Admin" OU custom role com:
       - analytics.readonly
       - analytics.accounts.read
   → Create key (JSON)
   ```

2. **Yan adiciona a Service Account como Viewer na GA4 property:**
   ```
   https://analytics.google.com/analytics/web/#/admin/property/...
   → Property access management
   → Add user: <service-account-email>
   → Role: Viewer
   ```

3. **Yan guarda JSON key em local SEGURO** (NÃO no chat):
   ```
   C:\Users\yan1n\.git-secrets\ga4-sa.json      ← arquivo
   $env:GOOGLE_APPLICATION_CREDENTIALS = "C:\Users\yan1n\.git-secrets\ga4-sa.json"   ← env var Windows User
   ```

4. **Yan obtém o GA4 Property ID numérico** (não confundir com `G-P9RKYHPB7Z`):
   ```
   https://analytics.google.com/analytics/web/#/admin/property/...
   → Property settings → Property ID (ex: 403020121)
   → $env:GA4_PROPERTY_ID = "403020121"
   ```

5. **Com credenciais em env var, eu implemento:**
   - Edge Function `supabase/functions/kc-ga4-reports/index.ts` que puxa dados via `googleapis` (já tem o pacote em `node_modules` se instalado)
   - Endpoint admin `/admin/ga4-dashboard.html` mostrando:
     - Pageviews 7d/30d/90d
     - Top pages
     - User acquisition (countries, devices, channels)
     - Custom events (sign_up, post_view, search, etc.) — esse aqui será o mais útil
   - Job cron diário que puxa totais para o Supabase (tabela `ga4_daily_stats`)

## 📐 Convenção de nomes de eventos

Padrão `kc_<verb>` para evitar conflito com eventos Google reservados (`login`, `purchase`, etc).
Parâmetros em snake_case, valores em lowercase.

| Evento | Trigger | Params obrigatórios |
|---|---|---|
| `kc_login` | usuário loga | `method: email\|google\|magic_link` |
| `kc_sign_up` | usuário cadastra | `method`, `invited_by: admin\|self\|invite` |
| `kc_logout` | usuário desloga | — |
| `kc_post_view` | carregamento de `product.html` | `post_id`, `module`, `category`, `source_unit` |
| `kc_post_create` | sucesso ao criar post | `module`, `category`, `is_external: bool` |
| `kc_post_share` | clique em share button | `method`, `post_id` |
| `kc_contact_click` | clique em "Entrar em contato" | `method: whatsapp\|email_public\|chat_internal\|external_link`, `post_id` |
| `kc_chat_open` | abrir conversa | `peer_role` |
| `kc_search` | submit de busca | `query`, `module`, `result_count` |
| `kc_module_filter` | clicar em módulo no feed | `module`, `tab` |
| `kc_cadu_run` | (Fase 2) pipeline rodou | `run_id`, `stages`, `items_published` |
