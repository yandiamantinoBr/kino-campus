### Edge Function `kc-ga4-reports` (v2 ACTIVE)

- **Arquivo**: `supabase/functions/kc-ga4-reports/index.ts`
- **Runtime**: Deno + Web Crypto API (zero deps externas — `googleapis` npm não roda no Deno)
- **Auth**: SA JSON → JWT RS256 → OAuth2 token exchange → cached token (in-memory)
- **Caller auth**: requer `Authorization: Bearer <supabase_jwt>` de usuário admin (`profiles.is_admin = true`)
- **CORS**: `KC_GA4_ALLOWED_ORIGINS` com fallback `*`; origens fora da allowlist recebem `origin_not_allowed`
- **Cache**: in-memory LRU max 50 entries, TTL `KC_GA4_CACHE_TTL_SEC` (default 300s, hard cap 3600s), chave estável profunda para filtros aninhados
- **Limite de consulta**: `KC_GA4_MAX_LIMIT` default 1000, hard cap 10000; dashboard atual usa limites pequenos (8, 10, 20)
- **Auto-deploy**: via `.github/workflows/edge-deploy.yml` (CI detecta mudanças em `supabase/functions/**`)
